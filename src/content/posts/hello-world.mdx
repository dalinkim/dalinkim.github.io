This site has had a few lives: a static HTML template, a Jekyll experiment, and now a Next.js rebuild. This time the goal is simple: **a calm place to write things down**.

## What to expect

I spend most of my days building data and AI/ML platforms, so expect posts about:

- Data engineering patterns that held up in production (and some that didn't)
- Notes from books and courses I'm working through
- Small experiments with new tools

## How this site is built

Every post is an MDX file in the repository. Writing a new one is just adding a file:

```bash
touch src/content/posts/my-new-post.mdx
```

The site is exported as static HTML and served by GitHub Pages.

<Callout variant="tip">
MDX lets a post use React components, like this callout, right alongside regular Markdown.
</Callout>
